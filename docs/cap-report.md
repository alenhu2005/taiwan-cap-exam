## 七、第三輪：數學 M1111 回饋與各科重新校準

出卷 AI 用新版出了一份會考數學卷（M1111），把卷子和 115 正式卷逐題比對後回報；另一份外部審閱也比對了同一卷。
平均難度對上了（預估 0.601，官方 0.603），但卷子不像會考：89% 是情境題、5 題統計機率、沒有圓、相似形、多項式、
根式，選項幾乎都是數字且大小順序打亂，多題用同一組 6-8-10 直角三角形，非選擇題擠在同一頁，題目多是參考書老題。
追查後發現多半是 Skill 自己的規則造成的，於是把**每一科（社會除外）**的規則都拿官方 113–115 卷重新量過。

| 問題 | 原因 | 修正 |
| :-- | :-- | :-- |
| 詳解的「可能出處：」被當成資料來源而擋下最終檢查 | 數學來源註記規則比對「出處：」 | 排除「可能出處」 |
| 題組 23–25 被排進「第二部分：非選擇題」 | 規劃工具假設第二節一定是題組 | 數學題組留在第一部分 |
| 非選擇題 1、2 與選擇題 1、2 題號衝突 | 規劃與展開工具用印出的題號 | 存成第 26、27 題，印「1.」「2.」，詳解標「非選擇題第1題」 |
| 書店折扣、百分比都被要求附資料來源 | 「數字＋單位」一律當統計數據 | 社會以外只有宣稱真實資料（年份、調查、統計、公布）才要；「某國」「某商店」免 |
| 情境題 89%，基本運算題被擠掉 | 數學情境題下限 60%，官方約 33–41% | 數學 30%–60%（新增上限）；國文改 30%、英語改 50%（官方實測） |
| 5 題統計機率，缺圓、相似形、多項式、根式 | 只隨機抽題材，沒有單元覆蓋 | 新增 `cap_units.py`：數學、國文、英語依官方逐題分類的單元範圍，自然依三科比例；規劃工具照官方題序排好單元 |
| 鑑別度預估全部 ≥ 0.42，過度樂觀 | 低鑑別題上限 3% 比官方嚴（數學 115 有 8%） | 低鑑別比例放寬到官方最高值；難題的預估鑑別度不得遠高於官方同等難題 |
| 預估通過率要依存檔順序累計才能過關 | 前幾題本來就易，平均必然超出區間 | 改成和已存題位的目標平均比較 |
| 審查欄位錯了才知道 | 範本缺 `status`、`observations`、非選擇題錨點鍵；`shared_reading_minutes` 預設 null；後續 `--plan` 不更新 metadata | 範本補齊；`auto-review` 另產生 `difficulty.draft.json`；預設數字；後續 `--plan` 會更新 metadata |
| 自己寫繪圖程式，「−」「…」「′」印不出、標籤白框、選項圖 18 pt | 沒有繪圖工具 | 新增 `cap_draw.py`（格線、坐標軸、點線圓角與記號、中文標籤、四張選項圖），標籤自動避線、只用細白邊 |
| 「C′」印成「C ´」、ABCD 不斜體、分數選項一行一個 | 撇號用中文字型、點名限 4 字母、量寬時把分數標記當 13 個字 | 撇號改 Times；會考數學大寫點名一律斜體（「Y 字型」等標籤除外）；分數依實際寬度量 |
| 參考公式頁右側「Sₙ，」「rⁿ⁻¹」被切 | 上下標繼承 14 pt | 上下標固定 9 pt，重建數學模板 |
| 選項數值大小順序亂 | 沒有規則 | 純數值選項須依大小排；`expand` 自動排序並同步改答案、誘答與詳解的 (A)～(D) |
| 前三題是文字應用題、後段難題太少 | 沒有難度曲線規則 | 第 1–3 題直接作答；前中後三段預估通過率須貼近官方同題位平均 |
| 沒有「甲、乙兩人的看法」判斷題 | 沒有規則 | 數學至少 2 題（官方每年 2–3 題） |
| 選項幾乎都是數字 | 沒有規則 | 至少 40% 的選項是關係、位置、算式、敘述或判斷（官方 12–14 題） |
| 參考書老題（梯子、圍籬、彈力球、骰子展開圖…） | 沒有規則 | 偵測常見老題型，每卷最多 2 題（官方 113–115 為 0） |
| 6-8-10 直角三角形用三次 | 沒有規則 | 同一組畢氏數最多出現在 2 題（題組算一題） |
| 非選擇題擠在同一頁 | 版面一路往下排 | 每題非選擇題獨立成頁，其餘當作答空間，不算留白 |
| 題型不夠創新 | 每題都是「情境＋算數字」 | 規劃工具給每個數學題位一個題型形式（直接作答、判斷兩人看法、推理關係、選出算式、讀新資訊建模、判讀圖表），只說學生要做什麼，不給情境 |

**詳解標注難易度與鑑別度（各科）。** 每題詳解在「課綱；可能出處」下一行印「難易度：中（預估通過率 0.62）；
鑑別度：優良（預估 0.45）」。有登錄的難度審查就用審查值，否則用出題時的預估；難易度用官方分類（易、中、難），
鑑別度用常見的優良、良好、尚可、待改進。兩者都標「預估」，因為沒有考生實際作答過。

其他科目依官方實測調整：英語正解最長與選項長短差的上限改用官方比例（英文單字長短天生不一）；國文選項的「毫無」「從不」
等字不再當極端字眼；英語字彙、文法題與國文語文知識題不受「多步推理」限制；寫作測驗依 113–115 固定框架檢查
（開頭語、思考問題、結合經驗或見聞、三條注意事項依序），詳解須依立意取材、結構組織、遣詞造句、錯別字格式與標點符號
四個向度說明。

## 八、第四輪：各科官方卷逐題分析與分科說明

國文、英語、自然 113–115 正式題本共 405 題逐題人工分類（數學 75 題已在第三輪分類），整理出每科的
**出題架構種類**、**出題習慣**（程式統計題幹問法、否定問法、圖表數量、選項結構），並**對照課綱**（國文、英語對應
學習內容類別，自然、數學對應冊別與單元）。分類結果只存標籤、不含原文：`exam_packs/會考/metadata/official-item-analysis.json`。

| 科目 | 主要發現 | 寫成的規則或工具 |
| :-- | :-- | :-- |
| 自然 | 三科題數三年幾乎不變（生物 13、理化 25–27、地科 10–12）；六冊每年都有 4 題以上，八下最多；架構：生活現象 11–12、圖表判讀 9–13、實驗探究 4–9、直接概念 5–10、判斷他人看法 1–6、計算 1–3、閱讀題組 8–9；問法以「最合理」「最可能」為主，否定問法 2–3 題；情境題約 62%–80% | 三科比例收緊到官方 ±3 題；六冊每冊 3–16 題；至少 4 題實驗探究、1 題判斷他人看法；否定問法最多 3 題；情境題下限改 60%；藍圖給每題架構與可能冊別 |
| 國文 | 五種單元三年穩定（資訊與圖表 14–15、文言 9–10、語文知識 8–9、白話 5–7、詩歌 2–4），文言加古典詩詞約三成；語文知識每年都有字音、字形、詞語成語、六書、字體各一題；問法約一半是「最恰當」，否定問法 3–5 題 | 單元範圍依新分類更新；藍圖保證五類語文知識都排到；否定問法最多 5 題 |
| 英語 | 單題字彙 9–12、文法 9–10，第 1 題每年看圖作答；題組題型三年加總：細節 16、推論 11、主旨或目的 11、應用 7、字義 6、指涉或比較 5；最後一組固定是克漏字；每年有一組異國文化說明文 | 單題至少一題附圖；題組（克漏字除外）的認知歷程有下限；藍圖給每個題組題位題型 |

- 尚未驗證：用新版 Skill 實際生成一整份會考卷。鑑別度與通過率是出題時的預估，不是實測；正式使用前仍建議由老師審閱。
