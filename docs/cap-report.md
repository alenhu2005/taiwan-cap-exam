## 二、與 115 會考比對後找到的問題（cap116a 社會卷）

把新關卡直接套在 cap116a 的出題資料上，並與 113–115 正式卷量測比較：

| 問題 | cap116a | 官方 113–115 | 處理 |
| :-- | :-- | :-- | :-- |
| 單題科別排列 | 歷 1–15、地 16–29、公 30–43，三大塊、換科 2 次 | 1–5 題一段交替，約 18 次換科 | 題序關卡＋`cap_plan.py` 自動排序 |
| 只有誘答使用絕對化字眼 | 17 題 | 每年 2–4 題 | 上限 5%，字眼清單含「只能、無權、連…也、就算」 |
| 正解是唯一最長選項 | 9 題（17%） | 0–7% | 上限 5% |
| 極端字眼（全體、廢除） | 2 個選項 | 496 個選項中 0 個 | 一律退件 |
| 數數題、算術題 | 第 46、50 題 | 0 | 退件 |
| 直接點名要考的概念 | 第 37、39–42 題等 | 多為轉譯型 | 社會 ≥ 60% 題目須記錄學生要推出、題幹不得出現的概念 |
| 答案可能有爭議 | 第 37 題（機會成本） | — | 每個誘答記錄「使它確定錯的課本定義或證據」 |
| 每題材料字數 | 中位數 76 字 | 69–110 字 | 在官方範圍內，不設字數門檻 |

**題序為什麼分科排：** SKILL.md 的學測社會規則要求「單題依科目排成連續區塊」，當時會考說明沒有寫相反規定，
出題 AI 便沿用學測規則。現已在 SKILL.md 明寫此規則不適用會考，並由關卡與工具強制穿插。

每題必須記錄：素養設計（情境、歷程、證據、先備知識、要推出的概念）、每個誘答的迷思、借用的相鄰概念、
預估選答率與排除依據、至少兩個環環相扣的判斷、課綱代碼與冊別。

## 四、減輕出卷 AI 的負擔

依生成考卷的 AI 回報（5.1 小時、上下文平均 44 萬 tokens、大多花在流程與報告）新增：

| 工具 | 解決的問題 |
| :-- | :-- |
| `references/cap-execution-card.md` | 一頁執行卡：指令順序、必填欄位、已知錯誤與解法；其他文件等工具點名再讀 |
| `scripts/cap_plan.py plan／item／check` | 會考藍圖與單題骨架（原本 AI 手寫約 400 行）；`emit_item_skeleton.py`、`check_paper_plan.py` 對會考改用它 |
| `run_hosted_workflow.py status` | 幾行進度摘要並寫 `NEXT.md`，每 2–3 批換新對話接續 |
| `run_hosted_workflow.py auto-review` | 實際執行檢查，寫好結構、難度分布、模板套用、答案分離四份報告 |
| 版面溢出訊息 | 直接指出題號、區塊與超出幾 pt（原本要逐塊二分法找） |
| 選項表格內距 | 修正會考 13 pt 字級下選項列超出版心 0.6 pt 的問題（只影響會考） |
| 罕用擴充字 | 存題時就擋下（例：「琅𤩝」改「琅嶠」），不必等最終建置 |

## 五、每次生成都不一樣（避免重複與提示詞污染）

| 問題 | 處理 |

| 同一天重複生成題材相同 | `cap_plan.py plan` 每次抽新的隨機種子分配題材方向（`suggested_focus`），只是起點，可自由發想 |

## 七、驗證

- 完整測試：1156 項通過、17 項略過；其中會考專屬測試 60 項，包含把 soc01、cap116a 的實際缺陷做成回歸測試。
- 模擬新對話：解壓 Skill ZIP 後，六科都能離線完成預檢（`ready-for-authoring`），並產生命題藍圖。
- 尚未驗證：用新版 Skill 實際生成一整份會考卷。鑑別度與通過率是出題時的預估，不是實測；正式使用前仍建議由老師審閱。

## 八、已知限制

- 英語聽力不製作。
- 版型為 A4（正式題本 595 × 822 pt）。
- 封面字型改用全字庫正楷體，單一封面約 0.87 MB，Skill ZIP 約 15 MB。
- 社會的科別交替規則依 115 卷人工分類量測；自然尚未量測，暫不要求穿插。
